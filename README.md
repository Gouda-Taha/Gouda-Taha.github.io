# My academic page

A three-page static site (About, Publications, Conferences & Talks). No build step.

## Fill it in
1. Open `index.html`, `publications.html`, `conferences.html` and replace every "Your Name" / placeholder.
2. Add your photo to this folder as `profile.jpg`.

## Publish on GitHub Pages
1. On github.com, create a **public** repository named `YOURUSERNAME.github.io` (or any name, e.g. `my-site`).
2. Upload all files in this folder to the repository root (Add file → Upload files → Commit).
3. Go to **Settings → Pages**, set Source to "Deploy from a branch", Branch `main`, folder `/ (root)`, and Save.
4. After about a minute your site is live at `https://YOURUSERNAME.github.io/` (or `https://YOURUSERNAME.github.io/my-site/` for a differently named repo).
